# VditorRenew - 面向 TypeRenew 的轻量 Vditor 编辑器插件
VditorRenew 是一款面向 TypeRenew 的轻量编辑器增强插件，适配 PHP 8 与 MySQL 8，将后台写作页接入 Vditor，提供 Markdown 写作、旧文兼容、本地草稿缓存、模式切换、主题跟随与完整静态资源内置能力。

## 功能特性
- **接管后台写作页**
  - 替换文章写作页编辑器
  - 替换独立页面写作页编辑器
  - 资源缺失时自动回退旧编辑器
  - 插件关闭后可直接回退旧编辑器
- **三种编辑模式**
  - 所见即所得模式
  - 即时渲染模式
  - 分屏预览模式
  - 可按配置控制是否允许页面内切换模式
- **旧文章兼容**
  - 支持旧文按原样内容继续编辑
  - 支持旧文自动转换为 Markdown 编辑
  - 在站点未开启 Markdown 时保留回退判断
  - 尽量兼容现有 Typecho / TypeRenew 写作链路
- **写作辅助能力**
  - 大纲面板
  - 字数统计
  - 表情输入
  - 代码高亮
  - 浏览器本地草稿缓存
- **界面与交互增强**
  - 跟随 Renew UI 深浅主题
  - 支持 `zh_CN` 与 `en_US` 界面语言
  - 支持 `ant` 与 `material` 两套图标
  - 可设置编辑区高度
  - 可配置全屏按钮兼容策略
- **工具栏扩展**
  - 内置默认工具栏
  - 支持使用 JSON 扩展或覆盖工具栏
  - 支持受控的自定义工具项
  - 对自定义项名称、提示与点击函数做基础校验
- **资源自带，部署直接可用**
  - 内置 Vditor 前端资源
  - 内置 KaTeX、Mermaid、ECharts、Markmap 等依赖资源
  - 不依赖外部 CDN
  - 更适合内网、离线或受限环境部署

## 适用场景
- 基于 TypeRenew 构建并希望升级后台写作体验的博客或内容站
- 需要 Markdown 写作、即时预览和更现代编辑交互的站点
- 希望兼容旧文章、又不想彻底破坏原有写作流程的场景
- 无法稳定依赖外部 CDN，希望插件自带完整编辑器资源的环境

## 安装方式
1. 将插件目录上传至站点的 `/usr/plugins/` 目录
2. 确保目录名称为 `VditorRenew`
3. 登录网站后台，进入“控制台 -> 插件”页面
4. 找到并启用 `VditorRenew`
5. 进入插件配置页，按需调整默认模式、旧文兼容策略和功能开关

## 配置说明
插件配置页主要包含以下选项：

- **编辑器状态**
  - 启用 Vditor
  - 回退旧编辑器
- **默认编辑模式**
  - 所见即所得
  - 即时渲染
  - 分屏预览
- **旧文章兼容策略**
  - 旧文按原样内容编辑
  - 旧文自动转换为 Markdown
- **功能开关**
  - 模式切换
  - 大纲面板
  - 字数统计
  - 表情输入
  - 本地草稿缓存
  - 跟随主题
  - 代码高亮
- **界面与交互**
  - 语言
  - 图标集
  - 编辑区高度
  - 全屏按钮策略
- **工具栏扩展**
  - 留空使用默认工具栏
  - 填写 JSON 数组自定义工具栏内容

## 兼容说明
- 插件只接管后台文章页和独立页面写作页，不改动前台渲染链路
- 当 Vditor 静态资源不完整时，插件会拒绝启用或在写作页回退旧编辑器
- 当旧文章不是 Markdown 且当前配置不允许强制转换时，会优先保留原有编辑路径
- 本地草稿缓存依赖浏览器 `localStorage` / `sessionStorage`
- 若站点或其他插件强依赖旧编辑器行为，建议先在测试环境中验证兼容性

## 目录结构
```text
VditorRenew/
├── assets/
│   ├── css/            # 编辑器桥接样式
│   ├── js/             # 写作页桥接脚本
│   └── vditor/         # Vditor 及相关前端静态资源
├── Plugin.php          # 插件主入口与配置处理
├── Bridge.php          # 写作页编辑器桥接层
└── README.md           # 仓库说明文档
```

## 注意事项
- 本插件的目标是增强 TypeRenew 后台写作体验，不负责前台文章样式美化
- 旧文选择“自动转换为 Markdown”前，建议先确认原内容格式与现有主题输出是否匹配
- 本地草稿缓存仅提升浏览器侧容错能力，不能替代正式保存或数据库草稿
- 如果未来需要自行更新 Vditor 资源，请确保 `dist` 目录结构完整，否则插件会判定资源缺失
- 若其他插件也修改写作页编辑器或注入同类脚本，请注意冲突风险
